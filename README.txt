==========================================
断末蚊
README
==========================================

■概要
==========================================

タイトル：
断末蚊

ジャンル：
蚊叩きカジュアルゲーム

開発環境：
HTML5 + JavaScript

操作：
画面上に出現する蚊をタップして撃破する。

目的：
蚊の吸血完了を阻止する。

コンセプト：

「煽る」
「現れる」
「倒される」

を楽しむテンポ重視の蚊叩きゲーム。

蚊は単なる敵ではなく、
口だけは達者なキャラクターとして描く。

撃破時や接近時のセリフ、
個体ごとの特徴を楽しむ
キャラクター性重視の設計。

==========================================
■セリフシステム
==========================================

蚊の個性を表現するため、
セリフシステムを実装。


関連ファイル：

dialogue.js

mosquitoDialogue.js

dialogueBubble.js

dialogueHistory.js


機能：

・出現時セリフ

・回避時セリフ

・撃破時セリフ

・属性によるセリフ変更


表示方式：

SINGLE

最新の蚊1匹のみ吹き出し表示。


MULTI

複数の蚊の吹き出しを同時表示。


セリフ履歴：

画面下部余白を利用。


仕様：

・新しいセリフは上へ追加

・古いセリフは下へ押し出し

・最大表示数設定可能

・蚊の種類による文字色変更


現在：

黒蚊
→ 黒文字

赤蚊
→ 赤文字



==========================================
■死亡・ゲームオーバー演出
==========================================


死亡時演出を実装。


関連ファイル：

death.js

gameOver.js

staffRoll.js


演出流れ：


吸血完了
または
規定回数吸血される

↓

画面停止

↓

赤フェード

↓

赤背景のGAME OVER表示

・リトライ

・タイトルへ戻る

↓

一定時間後

赤背景から黒フェード

↓

黒背景GAME OVER表示

↓

スタッフロール開始


スタッフロールは
GAME OVER表示の後ろで流れる。
