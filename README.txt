==========================================
■概要
==========================================

タイトル：
断末蚊

ジャンル：
蚊叩きカジュアルゲーム

開発環境：
HTML5 + JavaScript

操作：
画面上に出現する蚊をタップして撃破する。

目的：
蚊の吸血完了を阻止する。


==========================================
■ゲームコンセプト
==========================================

断末蚊は、

「煽る」
「現れる」
「倒される」

というテンポを楽しむ蚊叩きゲーム。

蚊は強敵ではなく、口だけは達者な存在として描く。

出現時、接近時、撃破時などに表示されるセリフによって、
蚊ごとのキャラクター性を楽しむ。

==========================================
■遊び方
==========================================

1．迫り来る蚊をタップして撃退しろ！

2．吸血を許すと「かゆみ」が蓄積するぞ！

3．♥が0になるか、吸血完了されるとゲームオーバーだ！


==========================================
■ゲームシステム
==========================================


■蚊の接近

蚊は画面奥から手前へ接近する。

layerによって遠近感を表現する。


FAR：
遠景。
小さい。
低速。


MIDDLE：
中景。
標準サイズ。
標準速度。


FRONT：
近景。
大きい。
高速。


FRONT到達後、
WARNINGへ移行する。


==========================================
■蚊の状態管理
==========================================

蚊は以下のphaseで管理する。


APPROACH

接近中。

処理：
・FAR→MIDDLE→FRONT移動
・撃破可能
・回避判定あり


WARNING

吸血開始前。

処理：
・撃破可能
・回避不可

最後の攻撃チャンス。


SUCKING

吸血中。

処理：
・吸血時間計測
・撃破可能


吸血中に撃破した場合、
かゆみ被害が発生する。


COMPLETE

吸血完了。

ゲームオーバー条件。


==========================================
■吸血システム
==========================================

WARNING時間：

1秒


吸血時間：

3秒


吸血完了されると即ゲームオーバー。


吸血中でも蚊を撃破することは可能。

ただし、吸血中の蚊を撃破した場合、
かゆみ被害回数が加算される。


==========================================
■かゆみ耐性
==========================================

プレイヤーにはハート3個の耐性がある。


初期値：

3


吸血中の蚊を撃破した場合：

かゆみ被害 +1


3回被害を受けるとゲームオーバー。


ゲームオーバー条件：

・吸血完了
・かゆみ耐性0

==========================================
■蚊データ管理
==========================================

蚊は性能データと個性データを分離して管理する。


colorType：

蚊の性能を管理。

管理項目：
・色
・速度
・出現率
・セリフ文字色


現在実装：

BLACK：
通常種。

RED：
高速種。


colorTypeは種類数が少ないため、
JavaScript設定で管理する。


------------------------------------------

attributeType：

蚊の個性を管理。

管理項目：
・属性名
・出現率
・回避率


外部データ：

data/attribute.csv


属性追加やバランス調整を容易にするため、
CSV管理を採用。


例：

新人蚊
中二病蚊


------------------------------------------

dialogue：

蚊のセリフ管理。


管理項目：

・出現時
・回避時
・撃破時
・吸血直前
・吸血完了時


外部データ：

data/dialogue.csv


属性ごとのセリフ追加によって、
蚊のキャラクター性を拡張できる。


==========================================
■セリフシステム
==========================================

断末蚊の個性要素。


機能：

・蚊ごとのセリフ管理
・吹き出し表示
・セリフ履歴表示


表示方式：

SINGLE：
最新の蚊1匹のみ表示。


MULTI：
複数の蚊を同時表示。


セリフ履歴：

画面下部領域を利用。


仕様：

・新しいセリフを上へ追加
・古いセリフを下へ押し出す
・最大表示数設定可能
・名前とセリフを分離


セリフ色：

BLACK：
黒文字。


RED：
赤文字。
